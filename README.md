# Chison USG Web

Статическое веб-приложение: показывает картинку с УЗИ-датчика, который определяется как USB-камера (UVC).
Снимок PNG, запись WebM, яркость/контраст, отражение, поворот. Всё работает в браузере, видео никуда не отправляется.

## Деплой на Vercel
    npm i -g vercel
    cd chison_web
    vercel --prod

Или загрузите папку в GitHub-репозиторий и импортируйте его в Vercel (Framework Preset: Other, сборка не нужна).

## Важно
- Камера доступна только по HTTPS (Vercel даёт его по умолчанию) или на localhost.
- UDP/Wi-Fi-режим в браузере и на Vercel невозможен: браузер не умеет UDP, а серверы Vercel не достанут до датчика в вашей локальной сети.
- Приложение не сертифицировано и не предназначено для медицинской диагностики.

## Журнал диагностики
Под картинкой есть «Журнал событий» (по-русски) и строка «Состояние» в панели справа. Галка «Подробно» показывает служебные строки. Кнопки «Копировать» и «Скачать .txt» отдают весь журнал вместе с версией браузера. Те же сообщения дублируются в консоль (F12) с префиксом `[USG]`.

Что отслеживается: HTTPS и политики камеры, разрешение браузера, список камер и их появление/исчезновение (кабель вставили/вытащили), какая именно камера открыта (датчик или встроенная), причины отказа (`NotAllowed`, `NotFound`, `NotReadable`, `Overconstrained`…), приходят ли реальные кадры и с какой частотой, зависание, чёрная или однотонная картинка, заморозка, отключение датчика, запись и снимки.
