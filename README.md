# Chison USG — программа для УЗИ-датчика

Подключение к беспроводному датчику Chison (Wi‑Fi UDP) и/или USB/UVC.
Лицензия: **always-valid** — любое устройство принимается, tenancy = −1.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
# Авто: сначала Wi‑Fi, иначе USB
python usg_app.py

# Только Wi‑Fi (подключитесь к AP датчика, сеть 192.168.0.x)
python usg_app.py -m wifi

# Только USB
python usg_app.py -m usb -d 0

# Список USB-камер
python usg_app.py --list-usb
```

## Сеть (Wi‑Fi)

1. Включите датчик, подключите ПК/телефон к его точке доступа.
2. IP датчика по умолчанию: `192.168.0.188`, порт `9000`.
3. Программа шлёт пакет `a` + heartbeat 1037 байт + freeTest-блок (tenancy=-1).
4. Принимает UDP-датаграммы и собирает B-mode изображение.

## Клавиши

| Клавиша | Действие        |
|---------|-----------------|
| `s`     | Снимок PNG      |
| `r`     | Запись AVI      |
| `h`     | Heartbeat сейчас|
| `q`/Esc | Выход           |

## Файлы

- `usg_app.py` — главное приложение
- `protocol.py` — UDP/heartbeat/CRC/freeTest-блок
- `license_bypass.py` — always-valid лицензия
- `snapshots/` — снимки и видео

## Замечания

Сборка кадра из Wi‑Fi-потока — best-effort (точные смещения полей заголовка линии зависят от прошивки).
Для точной геометрии строк нужен разбор живого трафика (см. протокол обмена).
USB/UVC режим использует стандартный VideoCapture (датчик как веб-камера).
